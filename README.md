# AI Sana Challenge Hub — Frontend

Frontend for the AI Sana Challenge Hub hackathon project.

## Implemented

- Landing page
- Challenge creation flow
- AI clarification interface
- Challenge readiness score UI
- Generated challenge view
- Challenge marketplace
- Challenge details page
- Team application modal
- Business dashboard
- Team selection flow
- Internal navigation between main pages
- Responsive layout with Tailwind CSS

## Main routes

- `/` — landing page
- `/create` — create and refine a business challenge
- `/challenges` — challenge marketplace
- `/challenges/[id]` — challenge details and team application
- `/dashboard` — business dashboard and application review
